## 元件重用與 UI 證據

兩個 AI 結果 route -> ActivityComparisonTable -> SqliteDataTable / DiffCell / ActivityEventDetailPanel。Full text 繼續使用 ContentDiffViewer；hunk-only 是 Source Trace 特有補充，非複製另一份完整 viewer。原 DB Overview、User Viewer、Issue Viewer、Connections、Settings 均以真實 renderer 開啟。

App-only capture 方法為 Playwright Electron + BrowserWindow.capturePage({stayHidden:true})；不使用 OS 桌面截圖。五種 renderer 尺寸：1920x1080、1440x900、1280x720、1024x768、800x600。涵蓋正常三頁、候選 popover、來源 tab、column chooser、空 DB、空篩選、SQL/facet error、更多 menu、preflight error、partial/source conflict、按鈕 hover/focus。DOM 檢查無全域 horizontal overflow；表格允許自身水平捲動。

Renderer zoom 1.25/1.5 不是 Windows 原生 DPI 測試，不宣稱 OS DPI PASS。人工 native DPI、全部滑鼠/鍵盤細節與真實使用情境仍由 GUI Gate 驗收。
