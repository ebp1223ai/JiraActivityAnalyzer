# v0.2.59 Description Diff Source Identity Verification Matrix

## Scope

This matrix covers the local SQLite Description evidence path only. SQLite schema remains v3, Jira access remains read-only, and no migration, ENV change, external SQLite dependency, or Jira request was added.

## Resource Guards

`shared/descriptionDiff.ts` centrally bounds canonical input size, full-context size, line count, rich-content nodes/depth, and diff work. A guard reports `diff-too-large` or `unparseable`; it never falls back to full After or Comment content.
