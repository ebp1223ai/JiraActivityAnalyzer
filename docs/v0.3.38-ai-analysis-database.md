# v0.3.38 AI Analysis Database

v0.3.38 introduces an independent, application-wide SQLite database at
`<JAA_DATA_ROOT>/databases/ai-analysis/jaa-ai-analysis.sqlite`.

## Import Contract

- The only accepted format is `jaa-ai-analysis-import-package` `1.0.0`.
- Draft 2020-12 JSON Schema, UUID/date-time formats, record order, counts,
  required capabilities, RFC 8785 hashes, dedupe identities, findings, and
  reviews are verified before preview is marked valid.
- Import begins only after explicit confirmation and runs in one
  `BEGIN IMMEDIATE` transaction.
- Review rank is `AI_ONLY < REVIEW_PARTIAL < REVIEW_COMPLETED`. Lower-ranked
  packages cannot replace higher-ranked records.
- Replacements retain the AI record identity, first import time, source-link
  attempts, and import-action history.

## Source Linking

The selected Source Archive SQLite is opened read-only. Primary matching uses
`sourceDatabaseId + activityEventId`; fallback matching uses source database,
stable record ID, field, and event time. Candidate identity and content are
verified before a link becomes `MATCHED`. Every attempt is append-only and the
current result is stored separately.

## Views

- **AI Analysis Database**: health, preview/confirm import, batch history,
  manual relink, and diagnostics export.
- **AI Results Viewer**: server-side filters and pagination from AI SQLite.
- **Integrated Results**: raw activity events remain the query base and are
  left-joined to current matched AI records, so unanalyzed events remain visible.

The legacy AI Analysis engine is retained in source but its sidebar entry is
disabled as **AI Analysis (Archived)**. Import and viewing do not contact Jira
or any AI provider and do not modify the raw Source Archive database.
