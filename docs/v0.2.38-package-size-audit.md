## Findings

- Electron and Chromium runtime files remain the dominant package cost.
- Packaged production dependencies occupy 21,758,306 bytes (20.750 MiB).
- The audit identified 86 dependency documentation/development-pattern files,
  totaling about 0.472 MiB. They are inherited from dependencies and were not
  removed because package minimization is outside the database-correctness
  change and an unsafe exclusion could break package resolution.
- `npm audit --omit=dev` reports two high-severity React Router advisories
  (`react-router` and `react-router-dom`) with no fix currently available.
- No duplicate physical files were reported by the package audit.

Machine-readable details, including the 50 largest files, 20 largest
directories, capacity categories, and unexpected content, are in:

- `reports/JiraActivityAnalyzer_v0.2.38_package_size_before.json`
- `reports/JiraActivityAnalyzer_v0.2.38_package_size_after.json`
